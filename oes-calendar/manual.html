1. このツールでできること

  • カレンダーから複数の作業日をまとめて選び、業態と時間帯を指定して予定を一括で作れます。
  • 業態ごとの定型文（説明文のひな形）を設定画面で自由に編集できます。
  • 担当者と担当者ごとの定型文も設定画面で追加・修正でき、予定に差し込めます。
  • 作った予定は、Googleカレンダーに1件ずつ順番に登録するか、ICSファイルで一括取込できます。
  • 作業当日は、その日の予定を読み込んで「入店連絡 / 中間報告 / 退店連絡」に自動で振り分け、ワンタップでコピーできます（Google Chat へ貼り付けて送信）。
  • パソコンでもスマートフォンでも同じように操作できます。
このツールは予定を「作る」ためのものです。予定そのものはGoogleカレンダー側に保存されます。ツールの登録リストは、ブラウザを閉じると消えます。

2. 画面の構成

タブ内容
📅 カレンダー作業日を複数選び、業態・時間帯・店舗名・住所を指定して、登録リストへまとめて追加します。
📋 登録リスト追加した予定を1件ずつ確認・修正し、Googleカレンダーへ登録します。タブの数字は現在の件数です。
🏃 作業当日その日の作業（業態・店舗・時刻）を確認し、連絡文をコピーして Google Chat に貼り付けます。
⚙️ 設定業態・時間帯・定型文、担当者と担当者定型文、タイトル書式などを編集します。内容はこの端末のブラウザに保存されます。

3. 基本の使い方（3ステップ）

  1. 作業日を選ぶ
    「📅 カレンダー」タブで、日付をタップ（クリック）します。何日でも選べます。もう一度押すと選択が外れます。
    パソコンでは、最初の日を押したあと Shift を押しながら別の日を押すと、その間の日をまとめて選べます。
    選んだ日は青くなり、下に一覧（チップ）で表示されます。
  2. 業態と時間帯を選ぶ
    業態を選ぶと、その業態に登録されている時間帯（午前・午後など）が表示されます。時間帯を選ぶと、開始・終了時刻が自動で入ります。時刻はその場で変更もできます。
    担当者を選ぶと、その担当者の定型文が説明文に差し込まれます（業態に「既定の担当者」を設定していれば自動で選ばれます）。
    店舗名・住所を入力しておくと、選んだ全ての日に同じ内容で入ります（あとから1件ずつ変更できます）。
  3. 登録リストに追加
    「選択した◯日を登録リストに追加」を押すと、選んだ日数ぶんの予定がまとめて作られ、「📋 登録リスト」タブに移動します。
    日付・業態・時間帯の組み合わせを変えて、この操作を何度でも繰り返せます。
例：「この日とこの日とこの日は、はま寿司の午前中」→ カレンダーで3日を選ぶ → 業態「はま寿司」＋時間帯「午前 (AM)」→ 追加。続けて別の日を選び、業態「すき家」＋「午後 (PM)」→ 追加。

4. Googleカレンダーへの登録方法（2通り）

A. Googleカレンダーで順番に登録（おすすめ・確認しながら）

  1. 「📋 登録リスト」タブの「Googleカレンダーで順番に登録」を押します。
  2. 1件目の内容が表示されるので「開く」を押します。Googleカレンダーの予定作成画面が新しいタブで開きます。
  3. 内容を確認して、Googleカレンダー側で「保存」を押します。
  4. このツールの画面に戻り、続けて「開く」を押して次の予定へ進みます。
ブラウザのポップアップブロックを避けるため、1件ずつボタンを押して開く方式にしています。「とばす」でその予定を飛ばせます。

B. ICSファイルで一括取込（件数が多いとき）

  1. 「📋 登録リスト」タブの「ICSファイルで一括取込」を押すと、oes-日付.ics がダウンロードされます。
  2. パソコンのブラウザでGoogleカレンダーを開き、右上の歯車 → 設定 → インポート／エクスポートを開きます。
  3. ダウンロードした ICS ファイルを選び、追加先のカレンダーを選んで「インポート」を押します。
  4. 件数が表示されれば完了です。
インポートは1件ずつの確認なしでまとめて登録されます。取り込む前に登録リストの内容をよく確認してください。時刻は日本時間（Asia/Tokyo）で書き出されます。

5. 登録リストの編集

  • 各カードで、日付・業態・時間帯・開始／終了時刻・担当者・店舗名・住所・説明文を1件ずつ変更できます。
  • 担当者を変えると、説明文の中の担当者部分も自動で入れ替わります。
  • 業態や時間帯を変えると、時刻と説明文がその設定の内容に入れ替わります。
  • 店舗名は、入力欄から離れたときに末尾へ自動で「店」が付きます（例：渋谷 → 渋谷店）。設定で変更・停止できます。
  • 住所はGoogleカレンダーの「場所」に入ります。
  • 説明文は定型文から自動生成されます（「定型文から自動生成」の表示）。手で書き換えると「手動で編集」に変わり、以後は自動更新されません。「定型文に戻す」で元に戻せます。
  • 複製：同じ内容の予定をもう1件作ります。削除：その予定だけ消します。全て削除：リストを空にします。
  • ＋ 空の行を追加：カレンダーを使わずに1件だけ手入力したいときに使います。

5-2. 作業当日：連絡文をコピーして Google Chat へ

作業当日は「🏃 作業当日」タブを使います。その日の予定を読み込むと、説明文が ①入店連絡 ／ ②中間報告 ／ ③退店連絡 の3つに自動で振り分けられ、それぞれ「コピー」ボタンが付きます。

読み込み方（3通り。どれか1つでOK）

方法内容事前準備
説明文を貼り付けるGoogleカレンダーで予定を開き、説明文をコピーして貼り付け欄に貼り、「貼り付けた内容で連絡文を作る」を押します。一番手軽で、準備は不要です。不要
登録リストから探すこのツールで作った登録リストの中から、その日の予定を探します。不要
Googleカレンダーから読み込むその日の予定を直接読み込みます。Apps Scriptの設定（下記）

候補が複数あるときは一覧から選びます。読み込むと「今日の作業」に業態・店舗名・時刻・住所が大きく表示されます（住所があれば「地図」リンクから地図を開けます）。

Google Chat への送り方

  1. 入店したら ①入店連絡 の「コピー」を押します。
  2. 「Google Chat を開く」（または Chat アプリ）で、送信先に貼り付けて送信します。
  3. 中間報告・退店時も同じように ② ③ をコピーして送信します。
文面はその場で直接書き換えられます（機器の台数を入れる、などもここで）。書き換えたあと元に戻したいときは「定型文から作り直す」を押してください。
Google Chat への自動送信は行いません。コピー → 貼り付け → 送信の手動操作です。送信前に内容を確認できるので、誤送信の心配がありません。

振り分けのしくみ

説明文を空行で区切られたかたまりに分け、「中間報告」と「退店報告」という言葉を目印に振り分けます。

  • 「中間報告」より前 → ①入店連絡（POSレジの行なども含みます）
  • 「中間報告」のかたまり → ②中間報告
  • 「退店報告」から後ろ全部 → ③退店連絡（入店・退店時刻、MPR等の台数を含みます）

定型文を書き換えて別の言い方にしている場合は、「⚙️ 設定」の「作業当日の連絡文」で目印の言葉を変更してください。目印が見つからないときは、全文が①に入ります（そのまま手で直せます）。

Googleカレンダーから直接読み込む設定（任意）

準備なしでも貼り付けで使えますが、Google Apps Script を用意すると読み込みが1タップになります。

  1. 「⚙️ 設定」→「Googleカレンダー連携」→「Apps Script のコードを見る」でコードをコピーします。
  2. script.google.com で新しいプロジェクトを作り、貼り付けて保存します。
  3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行するユーザー「自分」、アクセスできるユーザー「全員」で公開します。
  4. 表示された /exec で終わるURLを、設定の「Apps Script のウェブアプリURL」に貼り付けます。
  5. 「接続テスト」で「接続できました」と出れば完了です。
このURLを知っていれば誰でもその日の予定を読めてしまいます。URLは社外に共有しないでください。
「予定の絞り込み文字」に OES などを入れると、その文字をタイトルに含む予定だけを読み込みます。

6. 設定：業態ごとの定型文と時間帯

「⚙️ 設定」タブでは、業態ごとに時間帯と定型文を登録します。業態名をタップすると内容が開きます。

業態の項目

項目説明
業態名プルダウンに表示される名前（例：すき家）。
タイトル書式この業態だけタイトルを変えたいときに入力します。空欄なら共通設定の書式を使います。
既定の担当者この業態を選んだときに自動で選ばれる担当者です（「（指定なし）」も選べます）。
時間帯（名称）「午前 (AM)」「午後 (PM)」など、自由に付けられます。
開始／終了その時間帯を選んだときに自動で入る時刻です。
定型文説明文のひな形です。差し込み文字（下記）が使えます。

＋ 時間帯を追加で時間帯を増やせます（午前・午後以外に「夜間」なども作れます）。＋ 業態を追加で業態そのものを増やせます。

定型文で使える差し込み文字

差し込み文字置き換わる内容例
{業態}業態名すき家
{店舗名}店舗名渋谷店
{日付}作業日2026年9月10日(木)
{開始}開始時刻08:30
{終了}終了時刻09:30
{時間帯}時間帯の名称午前 (AM)
{担当者}担当者名山田太郎
{担当者定型文}その担当者に登録した定型文（複数行可）担当: 山田太郎
090-0000-0000
定型文を書き換えると、登録リストの中で「手動で編集」になっていない説明文はすぐに新しい内容に作り直されます。

共通設定

項目説明
予定のタイトル書式初期値は OES入替作業({業態} {店舗名})。→ OES入替作業(すき家 渋谷店)
店舗名の語尾を自動で補う「補う」にすると末尾に「店」を付けます。補う文字も変更できます。
時刻プルダウンの開始／終了／刻み初期値は 6時〜20時・15分刻み。

7. 設定：担当者と担当者定型文

「⚙️ 設定」タブの「担当者と担当者定型文」で、担当者を追加・修正・削除できます。

担当者を追加する

  1. 「＋ 担当者を追加」を押し、担当者名を入力します。
  2. 必要に応じて連絡先・所属を入力します（任意）。
  3. 担当者定型文を入力します。改行を含む複数行でもかまいません。
項目説明
担当者名プルダウンに表示される名前。{担当者} に差し込まれます。
連絡先・所属電話番号や所属などの控え（任意）。定型文に書けば予定にも入ります。
担当者定型文業態の定型文の中の {担当者定型文} の位置へそのまま差し込まれます。この中でも {業態} {店舗名} {日付} などの差し込み文字が使えます。

担当者定型文を予定に入れる

  1. 「業態ごとの定型文・時間帯」で、差し込みたい業態・時間帯の定型文を開きます。
  2. 入れたい位置に {担当者定型文}（名前だけなら {担当者}）と書きます。
  3. カレンダー画面または登録リストで担当者を選ぶと、その位置に内容が入ります。
{業態} {店舗名} 入店 {開始}
{担当者定型文}

{業態} {店舗名} 中間報告
　…
業態ごとに「既定の担当者」を決めておくと、その業態を選んだときに担当者が自動で入るので、毎回選ぶ手間がなくなります。
担当者を削除すると、その担当者を「既定の担当者」にしていた業態は「（指定なし）」に戻ります。すでに登録リストに入っている予定の担当者も外れます（Googleカレンダーへ登録済みの予定は変わりません）。

8. 設定の書き出し・読み込み（端末間の共有）

設定（業態・時間帯・定型文・担当者・作業当日の目印・カレンダー連携URL・共通設定）は使っている端末のブラウザに保存されます。パソコンとスマートフォンで同じ設定を使うときは、次のようにします。

  1. 設定が整っている端末で「設定を書き出す（JSON）」を押し、ファイルを保存します。
  2. そのファイルをもう一方の端末へ送ります（メール添付、クラウド保存など）。
  3. 受け取った端末でツールを開き、「設定を読み込む」からファイルを選びます。
「初期設定に戻す」を押すと、追加・変更した業態や定型文はすべて消えます。念のため先に書き出しておくことをおすすめします。
ブラウザの履歴・サイトデータを消すと設定も消えます。ブラウザのシークレット（プライベート）モードでは保存されません。

9. スマートフォンでの使い方

  • 操作はパソコンと同じです。カレンダーは1か月ずつ表示され、‹ › で月を移動します。
  • 日付はタップで選択／解除します（Shift+クリックの範囲選択はパソコンのみ）。
  • 「Googleカレンダーで順番に登録」を押すと、Googleカレンダーのアプリまたはブラウザが開きます。保存したらブラウザに戻って次へ進みます。
  • ICSファイルの取込は、パソコンのブラウザからGoogleカレンダーの設定画面で行うのが確実です。
  • 作業当日タブの「コピー」は、スマートフォンでもそのまま使えます。コピーしたあと Google Chat アプリに切り替えて貼り付けてください。
  • ホーム画面に追加しておくと、アプリのように起動できます（Safari：共有 → ホーム画面に追加）。

11. よくある質問・注意事項

Q. 登録リストはブラウザを閉じても残りますか？

残りません。作った予定はその場でGoogleカレンダーへ登録してください。設定（業態・定型文）は残ります。

Q.「開く」を押しても新しいタブが開きません。

ブラウザのポップアップブロックが働いている可能性があります。このページのポップアップを許可してください。

Q. 予定の時刻がずれます。

Googleカレンダー側のタイムゾーン設定をご確認ください。このツールは日本時間（Asia/Tokyo）で送信します。

Q. 間違えて登録しました。

Googleカレンダー側で予定を削除してください。ICSで取り込んだ予定も、カレンダー上から削除できます。

Q. 業態を削除できません。

業態は1件以上、時間帯も業態ごとに1件以上必要です。

Q. 作業当日タブの「コピー」が効きません。

ブラウザのコピー機能が使えない環境の可能性があります。その場合は文面を長押し（PCではドラッグ）して選択し、手動でコピーしてください。なお、この機能は https:// で配信されている状態が確実です。

Q. 連絡文の振り分けがうまくいきません。

説明文の中に「中間報告」「退店報告」という言葉があるか確認してください。別の言い方をしている場合は「⚙️ 設定」の「作業当日の連絡文」で目印を変更できます。振り分け後は手で直しても構いません。

Q. 担当者を選んでも説明文が変わりません。

業態の定型文に {担当者} または {担当者定型文} が書かれているか確認してください。また、その説明文が「手動で編集」になっていると自動更新されません。

Q. 説明文が更新されません。

その説明文が「手動で編集」になっていないか確認してください。「定型文に戻す」を押すと自動生成に戻ります。
