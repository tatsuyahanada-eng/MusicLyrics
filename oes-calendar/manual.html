OES入替作業APP操作マニュアル（かんたん版）

このアプリでできることは、大きく分けて5つです。それぞれのタブに対応しています。

  • 📅 カレンダー … Googleカレンダーへ予定をまとめて登録する
  • 🛠️ 作業当日 … 入店・中間・退店の連絡文を作ってコピー、Google Chatへ
  • 📋 コマンド一覧 … 機器の保守機能の操作手順を、画面上の機器で確かめる
  • 📄 レポートの見方 … 機器が印字するインストールレポートの読み方を確かめる
  • ⚙️ 設定 … 業態の定型文やよく使う文などを管理する（管理者のみ変更可。 画面が狭いときは歯車マークだけになります）

1Googleカレンダーに登録する（📅 カレンダー）

質問に答えていくだけで、Googleカレンダーへの登録まで進められます。担当者を選ぶ欄はありません。

  1. 業態と稼働件数を選ぶ
    その日にまわる業態と件数（1〜30件）を選びます。
  2. 日付・時刻・店舗名をまとめて入力する
    件数ぶんの行が並ぶので、1件ずつ日付・開始時刻・終了時刻・店舗名・住所（任意）を まとめて入力し、「登録リストへ」を押します。同じ日でも別々の日でもかまいません。
  3. 一覧を確認してGoogleカレンダーへ登録する
    「Googleカレンダーで順番に登録」で1件ずつ開いて保存するか、「ICSファイルで一括取込」で まとめてGoogleカレンダーに取り込みます。
画面には常に「次はここ」という案内が出るので、順番に進めば迷いません。 やり直したいときは①のカードにある「クリア（最初からやり直す）」を押してください （まだGoogleカレンダーへ登録していない③の一覧も一緒に消えます。1件以上あるときは確認が出ます）。

2当日の作業に役立つ機能（🛠️ 作業当日）

現場で使う連絡文をその場で作り、コピーしてGoogle Chatへ貼り付けるためのタブです。

  1. 業態と店舗名を選ぶ
    開始・終了時刻もあわせて選びます（業態の時間帯が初期値として入ります）。
  2. 「この内容で連絡文を作る」を押す
    ①入店連絡／②中間報告／③退店連絡の3つが自動で作られます。 業態にあらかじめ「手順書・資料」が登録されていれば、そのすぐ下にそのまま表示されるので、 探す手間なく開けます（画像はサムネイル、PDFは「PDF」の表示。PDFはタップするとダウンロードされ、 Acrobat Readerなど端末の既定のアプリで開けます）。 業態に「注意事項」が登録されていれば、該当する欄（①②③のいずれか）にそのまま表示されます （写真の撮り方など。複数登録されていれば全部表示されます）。
  3. コピーしてGoogle Chatへ
    各欄のすぐ下にある「コピー」でコピーします （③退店連絡だけは、特記事項欄のさらに下に「コピー」があります）。 「今日の作業」または画面下部「よく使う文」の上にある「Google Chat を開く」を押すと Google Chatが開きます（コピーした内容を上書きしてしまわないよう、このボタンは Chatを開くだけで、クリップボードには何もコピーしません）。 Chatの検索欄で店舗名などを入力して該当のルームを探し、コピーした文を貼り付けてください。

入店連絡・中間報告に一言足す

①入店連絡・②中間報告の上にチェック欄があります。チェックした文だけが本文に入ります。

①入店連絡②中間報告
POSレジ清算済み
POSレジ清算 今から開始をお願いいたしました		 高所の為、電源ケーブル流用させて頂きます
スパイラル多用の為、電源ケーブル流用させて頂きます
店舗名多忙の為、入替作業は状況見て実施します。

退店連絡（③）

選んだ機器（MPR・MST・HT・BC・BP）の台数だけが自動で反映されます。 本文欄の下にある「特記事項」に何か書くと、【特記事項】という見出し付きでそのまま追記されます （空欄なら何も入りません）。「コピー」は特記事項のさらに下にあります。

Googleカレンダーの説明文をそのまま貼り付けて振り分けることもできます（「別の方法」を開く）。 「クリア」でいつでも最初からやり直せます。画面下の「よく使う文」からは、短い一言をワンタップでコピーでき、 すぐ上の「Google Chat を開く」からその場でChatを開けます。

3保守機能の操作を確かめる（📋 コマンド一覧）

画面の中に「Monstera/Relier シミュレーター」（機器の操作パネル）があります。 「この操作はどのボタンを押すんだったか」を、その場で確かめられます。

  1. シミュレーターのすぐ下にある「調べたい操作」をプルダウンから選ぶ
    その操作がどんな場面で役に立つかの説明（登録されていれば、目立つ色の帯で表示されます）が出ます。
  2. 「順番に再生」を押す
    押すボタンが順番に光ります。「1つ進む」で1つずつ確認することもできます。 速さが合わないときは、「最初から」の横にある秒数のプルダウンで0.8〜3秒の間で変更できます。 その下には同じ手順を文章でも読める「簡易手順」が表示されます。
  3. 右側の「進行状況」を見る
    「9（2回） → 8 → 実行 → 完了」のように今どこまで進んだかと、「◯◯を押してください」 という案内文が表示されます。画面の表示が変わらない操作（伝票の印刷など）では、 ここに結果の説明が出ることがあります。
  4. 自分で押してみる
    画面の中のボタンは実際に押せます。手順どおりに押すと、機器と同じように画面の表示が変わります。 長押し（琥珀色に光ります）や2つ同時押し（◁と▷を一緒に長押しなど）、 同じボタンを連続で何回か押す操作（青く点滅し、あと何回か数字で出ます）、 押しまま（離さずに次のボタンへ進む操作。緑色に光ります）にも対応しています。 画面の左には実機側面の電源スイッチ （上＝ON／下＝OFF）もあり、「何かのボタンを押しながら電源を入れる」といった操作もそのまま再現できます。
プルダウンを選ばずに、いきなりボタンを押してもかまいません。 登録されている手順どおりに押せば、その画面が表示されます。「クリア」で最初の画面に戻ります。

🔴 コマンド記録開始（待機中の画面のプルダウンの右、管理者のみ）を 押すと、そのあと実際に押したボタンが順番にそのまま右側の「進行状況」に記録されていきます。 「⏹ 記録停止」を押すと「記録した操作」という名前でコマンド一覧に追加されるので、 「手順を追加・編集」から名前や画面の文言を書き足してください。

4レポートの見方（📄 レポートの見方）

機器が印字する「MONSTERA インストールレポート」の読み方を、 実物と同じ並びの印字例を見ながら確認できます。

  1. レポートはそのまま縦に全部並んでいます
    インストール情報 → システム情報 → ECT → MST → MPR → MD → HT の順に、 実機の印字と同じ並びで上から下まで続けて表示されます。見たいところまでスクロールしてください。
  2. 行にマウスを乗せる（スマホはタップ）
    その行が何を表しているのか、どのファイル（xg-hardwre.ini など）の設定が出ているのかが表示されます。
  3. 値にマウスを乗せる（スマホはタップ）
    その値だけの詳しい説明が出ます。値の上にある A・B・C…の記号は 「項目一覧」と対応していて、どちらかに触れるともう一方も光ります。
レポートは項目どうしが隙間なく並ぶ場所があります（例：最終接続日時と現メニューバージョン）。 記号と下線の区切りを目印にすると、どこからどこまでが1つの値か分かります。

📌 注意事項（印字例の上のカード）には、現場で気づいた注意点を 誰でも読めます。追加・削除したいときは「🔒 追加する」を押し、管理者パスワードを入れると その場で追記できます（設定タブに移動する必要はありません）。

行や値にマウスを乗せて（タップして）説明が出ると、その下に 💬 コメント欄も出ます。その項目だけのメモを残せる欄で、こちらも「🔒 コメントを追加」から その場でパスワードを入れて追記できます。

5設定の項目（⚙️ 設定）

設定は全員で共有されます。誰かが直せば、次にアプリを開いた全員の画面に反映されます。 そのため変更には管理者パスワードが必要です（閲覧だけなら誰でもできます）。

項目内容
業態ごとの定型文・時間帯・注意事項業態の追加・並び替え、時間帯と定型文の編集、注意事項（写真の撮り方など）の登録 （①②③のどこに表示するか選べる、複数登録できる）
業態ごとの手順書・資料（画像・PDF）作業手順書や注意事項の画像・PDFを登録すると、 作業当日タブでその業態を選んだときに探すことなくそのまま開けます（1件30MBまで）。 アップロード・削除は管理者のみ行えます
入店連絡・中間報告に足す文作業当日タブのチェック欄に並ぶ文の追加・並び替え・削除
よく使う文作業当日タブ下部のコピー用チップに並ぶ短い文
コマンド一覧（保守機能の操作手順）「📋 コマンド一覧」タブで使う操作手順の登録。 待機中の画面は複数登録でき、名前・1〜2行目を自由に書き換えられます（プルダウンで切り替え）。 操作ごとに「始める前の待機画面」も、コマンド一覧の見出しから直接（開かなくても）指定できます。 押すボタンを順番に並べ、必要に応じて「長押し」「押しまま（離さずに次へ進む）」「同時に押すボタン」 「連続で何回か押す」「画面の1〜2行目に出る文字」「結果コメント（画面が変わらない操作の説明）」を 設定します。押すボタンは並び替え（↑↓）できるほか、各行の「＋」や一覧先頭の「＋ 先頭に追加」で、 押し忘れたボタンをあとから途中に差し込むこともできます。「複製」ボタンで似た操作をコピーしてから 一部だけ書き換えることもできます。一覧は折りたたみ式で、見出しをタップすると詳しい編集欄が開きます。 CSVでまとめて書き出し・読み込みもできます
共有設定の保存編集した内容を全員に反映させる（サーバーに自動保存、または settings.json をアップロード）
サーバーの状態をチェック設定が反映されない・インストールできないときの原因を自動で調べる
アプリとしてインストール画面最下部のリンクから、ホーム画面に追加できる
管理者パスワードは設定タブの一番上で入力して「解除」を押すと編集できます（パスワードは管理者にお尋ねください）。 作業が終わったら「保存してロック」を押しておくと、変更が保存されたうえでロックされるので安心です （このボタンは設定タブの一番上と、一番下の「共有設定の保存」のところの2箇所にあります）。
