# さくらのレンタルサーバへの設置手順（PHP + MySQL + PWA）

所要時間の目安：30〜60 分。SSH は不要で、コントロールパネルと FTP だけで完了します。

---

## 0. 前提の確認

| 項目 | 必要な条件 | 確認場所 |
|---|---|---|
| プラン | **スタンダード以上**（MySQL が使えるプラン） | 会員メニュー → 契約情報 |
| PHP | 8.0 以上（推奨 8.1〜8.3） | コントロールパネル → スクリプト設定 → PHP のバージョン |
| データベース | MySQL 8.0 を 1 つ作成できること | コントロールパネル → データベース |
| 独自ドメイン / SSL | **HTTPS が有効であること（PWA に必須）** | コントロールパネル → ドメイン/SSL |

> **HTTPS は必須です。** Service Worker（PWA の中核）は https のページでしか動作しません。
> さくらのレンタルサーバは無料の Let's Encrypt SSL を利用できます。

---

## 1. データベースを作成する

1. コントロールパネル → **データベース** → 「新規追加」
2. データベース名（例：`library`）、文字コードは **UTF-8（utf8mb4）** を選択
3. 作成後に表示される次の 4 つを控えます。
   - データベースサーバ（例：`mysql3306.db.sakura.ne.jp`）
   - データベース名（例：`アカウント名_library`）
   - ユーザー名（通常はアカウント名）
   - パスワード

## 2. テーブルを作成する

1. コントロールパネルの **phpMyAdmin** を開き、上記ユーザーでログイン
2. 左側で作成したデータベースを選択 → 上部の **「インポート」** タブ
3. `sql/schema.sql` を選択して実行 → 5 つのテーブルが作成されます
   （`lp_users` / `lp_items` / `lp_updates` / `lp_update_files` / `lp_audit_log`）
4. 続けて `sql/seed_admin.sql` をインポート → ログインID `welsys` / パスワード
   `Password` の初期管理者が作成され、そのままログインできる状態になります
   （詳しくは手順5）
5. 表示確認用のサンプルを入れる場合のみ、続けて `sql/seed_sample.sql` もインポート
   （本番データを入れる前に削除できます。ファイル冒頭に削除用 SQL を記載）

## 3. ファイルをアップロードする

FTP ソフト（FileZilla、WinSCP など）または コントロールパネルの **ファイルマネージャー** で、
`library-portal` フォルダの中身を公開ディレクトリへ転送します。

```
~/www/library/            ← 例：https://ドメイン/library/ で公開する場合
  ├ index.php
  ├ login.php  logout.php  settings.php  setup.php
  ├ manifest.webmanifest   service-worker.js   offline.html
  ├ .htaccess
  ├ api/        （items.php / updates.php / users.php / password.php）
  ├ assets/     （css / js / 画像・アイコン）
  ├ includes/   （config.php / db.php / auth.php / helpers.php + .htaccess）
  ├ sql/        （schema.sql / seed_sample.sql + .htaccess）
  └ docs/       （この手順書など + .htaccess）
```

`preview.html`（デザイン確認用）は本番では不要です。アップロードしなくて構いません。

> **転送モードは「バイナリ」または「自動」**にしてください。テキストモードで転送すると
> UTF-8 の日本語が壊れることがあります。

## 4. 接続情報を設定する

1. `includes/config.sample.php` をコピーして **`includes/config.php`** を作成
2. 手順 1 で控えたデータベース情報を記入
3. `'secure_cookie' => true`（https で運用するため）のままにする

```php
'db_host' => 'mysql3306.db.sakura.ne.jp',
'db_name' => 'アカウント名_library',
'db_user' => 'アカウント名',
'db_pass' => '設定したパスワード',
```

`includes/` には `.htaccess` を同梱しており、ブラウザから直接アクセスできないようにしてあります。

## 5. 最初の管理者を作成する

**すでに初期アカウントが1件用意されています。** 手順2でスキーマと一緒に
`sql/seed_admin.sql` もインポートした場合は、次の情報でそのままログインできます。

| ログインID | パスワード |
|---|---|
| `welsys` | `Password` |

**ログイン後、必ずメニューの「パスワード変更」からすぐに変更してください。**
初期パスワードのままである間は、画面上部に変更を促す通知が表示され続けます。
別のログインIDにしたい場合は、`setup.php` を使わず、ログイン後の
「設定 — 利用者管理」から新しい管理者を追加し、`welsys` は削除してください。

`seed_admin.sql` を使わない場合は、従来どおり `setup.php` から作成します。

1. ブラウザで `https://ドメイン/library/setup.php` を開く
2. ログインID・表示名・パスワード（8文字以上・英数字を含む）を入力して作成
3. 作成後、**`setup.php` をサーバーから削除**してください
   （利用者が 1 人でも登録されると自動的に無効化されますが、削除するのが確実です）

いずれの方法でも、最終的には `setup.php` をサーバーから削除しておくと安全です。

## 6. 動作確認

1. `https://ドメイン/library/` を開き、作成した管理者でログイン
2. 「＋ アイテム」でアプリ・資料を登録し、「＋ 更新を登録」で更新履歴を追加
3. 右上のメニュー → **設定（利用者管理）** で利用者を追加
   - **管理者**：登録・編集・利用者管理まですべて可能
   - **閲覧のみ**：一覧と更新履歴の閲覧・ダウンロードのみ

## 7. PWA としてインストールする

HTTPS で表示していれば、そのままアプリとして追加できます。

| 端末 | 手順 |
|---|---|
| iPhone / iPad（Safari） | 共有ボタン → 「ホーム画面に追加」 |
| Android（Chrome） | 右上メニュー → 「アプリをインストール」 |
| Windows / Mac（Chrome / Edge） | アドレスバー右のインストールアイコン → 「インストール」 |

追加後はアドレスバーのないアプリとして起動します（`display: standalone`）。

**キャッシュの方針**：CSS・JavaScript・画像のみを端末にキャッシュし、
画面本体（index.php）と API はキャッシュしません。利用者ごとに内容と権限が異なるため、
データを端末に残さない方針としています。オフライン時は案内画面（offline.html）を表示します。

**更新の反映**：CSS / JS を修正した場合は、各ファイルを読み込んでいる箇所の
`?v=4` の数字を上げ、`service-worker.js` の `CACHE = 'library-portal-v4'` も
同時に上げてください。次回アクセス時に新しいキャッシュへ切り替わります。

## 8. 運用上の注意

- **バックアップ**：phpMyAdmin の「エクスポート」で定期的に SQL を保存してください。
  さくら側の自動バックアップはプランにより異なります。
- **ファイル実体**：zip や PDF はデータベースに入れず、従来どおり共有サーバー等に置き、
  その URL を登録します（データベースの肥大化を防ぐため）。
- **パスワード**：`password_hash()` によるハッシュで保存され、元に戻すことはできません。
  忘れた場合は管理者が「編集」から再設定します。
- **ログイン制限**：パスワードを 5 回連続で間違えると 10 分間ロックされます（`config.php` で変更可）。
- **操作ログ**：ログイン・登録・利用者変更は `lp_audit_log` テーブルに記録されます。

## 9. うまく動かないときは

| 症状 | 確認すること |
|---|---|
| 「データベースに接続できません」 | `includes/config.php` の 4 項目。パスワードの前後に空白が入っていないか |
| 画面が真っ白 | コントロールパネル → エラーログ。PHP のバージョンが 8.0 未満でないか |
| ログイン後すぐログイン画面に戻る | `secure_cookie` が `true` のまま http で開いていないか（https でアクセスする） |
| ホーム画面に追加できない | https でアクセスしているか。`manifest.webmanifest` と `assets/icon-192.png` が転送されているか |
| 日本語が「?」になる | データベースの文字コードが utf8mb4 か。FTP をバイナリモードで転送したか |
