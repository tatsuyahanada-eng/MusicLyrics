VertiCale 導入・移行の手順（v53：データベース保存＋画面でのログイン）
====================================================================

■ いま使っている環境をそのまま切り替える場合（登録済みの予定は消えません）

  1. zip の中身を、これまでと同じフォルダに上書きアップロードします。
     （api.php と config.sample.php が新しく増えます。sync.php は「以前の方式のデータの
       取り込み」に使うので、そのまま置いておきます）

  2. パソコンで schedule.html を開きます。「初期設定」の画面が出ます。
       ・予定の保存先 …「かんたん」（設定不要）か「MySQL / MariaDB」を選ぶ
       ・管理者のアカウント … これからログインに使うIDとパスワードを決める

  3. 「この端末には、これまでに登録した内容が保存されています」と出たら「引き継ぐ」を押します。
     その端末に入っている予定・希望・ToDo が、そのままデータベースに保存されます。
     以前の「合言葉」でサーバに保存していた内容も、自動で突き合わせて取り込みます。

  4. スマホでも schedule.html を開き、同じIDとパスワードでログインして「引き継ぐ」を押します。
     スマホにしか無かった予定も足され、同じ予定は新しいほうが残ります（消えるものはありません）。

  5. ログインできることを確認できたら、サーバにある .htaccess と .htpasswd（Basic認証）を
     削除してかまいません。残したままでも動きますが、ログインが二重になります。

  ※ 切り替える直前の内容は、念のため各端末の中に控えを残しています
    （設定 →「アカウントとデータ共有」→「以前の方式（合言葉）からの引き継ぎ」）。
  ※ 心配な場合は、切り替える前に 設定 →「バックアップ保存」でファイルに保存しておいてください。
  ※ すべての端末で切り替えが済んだら、sync.php と schedule-data フォルダは削除してかまいません。


■ 新しいサーバに置く・ほかの人に譲る場合

  1. zip の中身をすべてアップロードして schedule.html を開くと、「初期設定」から始まります。
  2. MySQL の接続先をあらかじめ決めておきたいときは、config.sample.php を config.php という名前で
     コピーし、データベース名・ユーザー名・パスワードを書き換えてからアップロードします。
     （この場合、画面では管理者アカウントだけを登録します）
  3. 予定のデータも渡すときは、元の環境の「バックアップ保存」で保存したファイルを、
     新しい環境の「バックアップ読込」で読み込みます。


■ サーバに必要なもの

  ・PHP 7.2 以降（PDO と、pdo_sqlite か pdo_mysql のどちらか）
  ・「かんたん」を選ぶ場合は、このフォルダに書き込みができること
    （data フォルダと config.php が自動で作られます）
  ・https でのアクセスをおすすめします（ログイン情報を安全に送るため）


■ 自動で作られるファイル（消さないでください）

  ・config.php … データベースの接続先
  ・data/      …「かんたん」を選んだときのデータベース本体。外部から読めないよう、
                 中に .htaccess が自動で作られ、ファイル名も推測できない名前になります


■ データベースの中身（別のシステムと連携するとき）

  テーブル名はすべて vc_ で始まります。
    vc_users            ユーザー（パスワードはハッシュで保存）
    vc_jobs             予定（日付・開始・終了・案件名・タイトル・業務内容・区分 と、全項目を入れた data 列）
    vc_wishes           希望（稼働可／休み希望）
    vc_todos            ToDo
    vc_job_tombstones / vc_todo_tombstones   削除の記録（他の端末にも削除を伝えるため）
    vc_user_state       ユーザーごとの設定と、保存した回数（rev）
    vc_sessions / vc_login_attempts / vc_meta   ログイン状態などの管理用
