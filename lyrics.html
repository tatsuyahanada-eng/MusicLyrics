APIキーの取得方法とよくあるエラー
  1. Google Cloud Console でプロジェクトを作成
  2. 「APIとサービス」→「ライブラリ」で YouTube Data API v3 を検索し有効化
  3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」を選択
  4. AIza... で始まるキーをコピーし、上の欄に貼り付けて「保存して検証」

制限について： APIキーにHTTPリファラ制限を設定する場合は、このページのURL （）を許可リストに追加してください。制限なしでも動作しますが、無料枠を超えた利用を防ぐため 1日のクォータ上限を設定することをお勧めします。
