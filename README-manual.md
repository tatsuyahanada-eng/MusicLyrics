# Case By Case — ツリー型 作業マニュアル（サーバーDB共有版）

大項目を選ぶと枝分かれし、最終的な作業手順まで案内する「チャットボット風」のツリーマニュアルです。
**サーバー（PHP + MySQL）に接続すると、みんなの入力が1つのマニュアルとして蓄積・共有**されます。
画像の貼り付けにも対応します。未接続でもこの端末内（localStorage）だけで動作します。

## 仕組み（データの一元管理）

- **サーバー（DB）を唯一の正データ**とし、項目（ノード）ごとに 追加 / 更新 / 削除 / 並び替え します。
  「ファイル丸ごと上書き」をしないため、複数人が同時に編集しても**他の人の入力を消しません**。
- 各端末は起動時にサーバーから読み込み、編集は即サーバーへ反映。
  「最新に更新」ボタン＋約30秒ごとの自動更新で、他端末の変更も表示されます。
- テーブルは1つ（`nodes`）。列は将来の拡張にもそのまま使えます。

| 列 | 意味 |
|---|---|
| `id` | ノードの一意ID |
| `parent_id` | 親のID（空＝大項目/カテゴリ） |
| `sort_order` | 同じ親の中での並び順 |
| `title` | 選択肢に表示される項目名 |
| `body` | 説明・手順（Markdown風。画像 `![](uploads/xxx.jpg)` も可） |
| `updated_at` / `created_at` | 更新・作成時刻（ミリ秒） |

## ファイル構成

| ファイル | 役割 |
|---|---|
| `manual.html` / `manual.css` / `manual.js` | アプリ本体 |
| `manifest.webmanifest` / `sw.js` / `icon*.png/svg` | PWA（インストール・オフライン） |
| `api.php` | サーバーAPI（DB操作・画像アップロード） |
| `db.php` | DB接続・テーブル自動作成（PDO） |
| `config.sample.php` | 設定サンプル（→ `config.php` にコピー） |
| `data/` | SQLite利用時のDB置き場（`.htaccess`で直接アクセス禁止） |
| `uploads/` | アップロード画像の保存先（`.htaccess`でスクリプト実行禁止） |

## ロリポップ! への設置手順

### 1. データベースを作成
ユーザー専用ページ →「サーバーの管理・設定」→「データベース」→「データベース作成」。
表示される **サーバー / データベース名 / ユーザー名 / パスワード** を控えます。
（※ロリポップはMySQLです。PostgreSQLは提供されていません）

### 2. PHPバージョン
ユーザー専用ページ →「PHP設定」で **PHP 7.4 以上** を選択。

### 3. ファイルをアップロード
本一式を公開フォルダ（例: `/casebycase/`）へFTPでアップロード。

### 4. config.php を作成
`config.sample.php` を **`config.php`** にコピーし、DB情報を記入：

```php
define('DB_DRIVER', 'mysql');
define('DB_HOST', 'mysql-XXXXX.phy.lolipop.lan'); // 手順1のサーバー名
define('DB_NAME', 'LAA0000000-casebycase');       // データベース名
define('DB_USER', 'LAA0000000');                  // ユーザー名
define('DB_PASS', '設定したパスワード');
define('API_TOKEN', '好きな合言葉');               // 公開URLでは必ず設定
```

### 5. 書き込み権限
FTPソフトで、`uploads/` フォルダのパーミッションを **705（必要なら 707）** に設定。
（テーブルは初回アクセス時に自動作成されます）

### 6. 開く
`https://お使いのドメイン/casebycase/`（または `manual.html`）を開く。
編集モード →「サーバー連携」で **DB接続済み（共有中）** と表示されれば成功です。
`API_TOKEN` を設定した場合は、編集する人が「編集トークン」に同じ合言葉を入力します。

## 使い方（画面）

- **案内モード**: 大項目 → 分岐 → 最終作業項目まで選択で進む。
  - 表示中の項目は右上「この項目を編集」で直接修正、下部「＋ ○○を追加」でその場に子項目/大項目を追加できます。
  - 本文の**文字装飾**（編集ダイアログのボタン、または記法で入力）:
    `**太字**` / `[color=red]色付き[/color]`（red,blue,green,yellow,cyan,white,#RRGGBB）/
    `[big]大[/big]` `[xbig]特大[/xbig]` `[small]小[/small]` / 行頭 `# 見出し` `- 箇条書き`。
- **編集モード**: 追加・修正・削除・並び替え（ドラッグ&ドロップ対応）。変更は即サーバーへ共有。
  - 項目のタイトルをクリックすると内容を編集できます。
  - 説明欄では **「画像を追加」「ファイルを添付」** ボタン、または **貼り付け（Ctrl+V）** で挿入。
  - **記入者名** を入れておくと、追加・修正した人と時刻が記録されます。
  - **Excel一括登録 / Excel出力 / Excelひな型**: Excelでまとめて登録・書き出し（下記）。
  - **CSV出力 / CSV取込**: バックアップや上級者向けの入れ替えに。
  - **サーバー連携**: 接続状態、編集トークン、「最新に更新」、「この端末の内容をサーバーへ登録」。

## 項目ごとの閲覧ロック（パスワード保護）

特定の項目を、パスワードを知っている人だけに見せられます。

- 項目の作成・編集ダイアログで **「🔒 閲覧パスワードでロックする」** にチェックし、パスワードを設定します。
  - 既定は **ロックなし**（従来どおり全員が閲覧可）。パスワードは任意です。
  - ロックした項目は、その **配下（子・孫）もまとめて保護** されます。
  - 案内モードでは 🔒 と「要パスワード」が表示され、開くときにパスワードを求められます。
- **管理者パスワード** はどの項目でも閲覧できます。忘れた項目の確認に便利です。
  - `config.php` の `ADMIN_PW`（既定 `Welsys1234`）で設定します。未設定なら既定値が使われます。
- **パスワードの上書き**: 編集ダイアログでチェックを入れたままパスワードを入れ直すと変更できます。
  - パスワード欄を **空のまま** 保存すると、今のパスワードを維持します。
  - **チェックを外して** 保存するとロック解除になります。
- DB(共有)モードでは、ロック項目の本文は **サーバーからも送信されない** ため安全です
  （正しいパスワードか管理者パスワードで解除したときだけ本文を取得します）。

## Excelで一括登録

担当者がExcelでまとめて入力し、取り込めます（アプリ内でSheetJSを使い、外部通信なし）。

1. 編集モードの **「Excelひな型」** ボタンでひな型（`登録用ひな型.xlsx`）を入手（同梱の `template/登録用ひな型.xlsx` でも可）。
2. 「登録」シートに、**大項目 / 中項目 / 小項目 / 内容（手順・説明）/ 記入者** を1行ずつ入力。
   - 同じ大項目・中項目は各行に繰り返してOK（自動でまとめられます）。
   - 中項目・小項目を空欄にすると、上位の項目に内容が付きます。
   - さらに深い階層は「第4階層」「第5階層」列を足せます（最大6階層）。
   - 内容はセル内改行(Alt+Enter)で段落、行頭「- 」で箇条書き、「# 」で見出し。
3. **「Excel一括登録」** ボタンでファイルを選択し、**置き換え**（全入替）か **追加登録** を選びます。
4. **「Excel出力」** で現在の内容を同じ階層形式の `.xlsx` に書き出せます（バックアップ・再編集用）。

## API（api.php）概要

`api.php?action=...`。`API_TOKEN` 設定時、**書き込み系**はヘッダ `X-Api-Token` が必要（閲覧は不要）。

| action | メソッド | 内容 |
|---|---|---|
| `config` | GET | 接続確認（DB接続の有無・トークン要否） |
| `tree` | GET | 全ノードを取得（ロック項目は本文を伏せ `locked:1` で返す） |
| `node_create` | POST `{parent_id,title,body[,lock_enabled,lock]}` | 追加 |
| `node_update` | POST `{id,title,body[,lock_enabled,lock]}` | 更新（ロック設定の変更・上書き可） |
| `unlock` | POST `{id,password}` | 閲覧ロック解除（正しいパスワードか `ADMIN_PW` で対象サブツリーを返す） |
| `node_delete` | POST `{id}` | 削除（子孫も一括） |
| `node_move` | POST `{id,dir}` | 並び替え（±1） |
| `replace_all` | POST `{nodes:[...]}` | 全置換（CSV取込・移行用） |
| `upload` | POST (multipart `file`) | 画像アップロード → URLを返す |

## アップデート（差し替え）時の注意

データ本体は **MySQL（DB）に保存**されます。アプリのファイル（`manual.*` / `api.php` /
`db.php` / `vendor/` など）を新しくしても **DBの中身は消えません**。ただし次のものは
**上書き・削除しないでください**。

| 対象 | 理由 |
|---|---|
| `config.php` | DB接続情報（サーバー名・パスワード）。**上書きするとDBに繋がらなくなり、各端末が「この端末のみ」表示になって内容が食い違います。**（更新用ZIPには同梱していません） |
| `uploads/` の中身 | アップロードした画像・ファイルの実体。消すと添付が表示できなくなります |
| `data/` の中身 | SQLite利用時のDB本体。MySQL利用なら無関係ですが、消さないのが無難 |

更新手順:
1. 更新用ZIP（`config.php` を含まない）をFTPでアップロードして上書き。
2. 各端末で**ブラウザを再読み込み**（スマホでPWA追加済みならアプリを再起動）。

## 「スマホとPCで内容が違う」ときの確認

内容が共有されるのは、画面上部のチップが **「● 共有中」** のときだけです。

- **● 共有中** … DBに接続済み。全端末で同じ内容が見えます。
- **● DB未接続** … `config.php` の設定（パスワード等）またはPHPバージョンを確認。
- **● この端末のみ** … サーバーに繋がっておらず、その端末の編集は共有されません。

食い違う場合のチェック:
1. 各端末で上部チップが「● 共有中」か確認（違えば config.php を確認）。
2. 編集トークンを設定している場合は、各端末で同じ合言葉を入力。
3. それでも古い場合は編集モードの「最新に更新」ボタン、またはブラウザ再読み込み。

## セキュリティ / 運用の注意

- **公開URLで運用する場合は `API_TOKEN` を必ず設定**してください（未設定だと誰でも編集可能）。
- `config.php`（DBパスワード等）は Git に含めません。サーバーへ直接アップロードします。
- `uploads/` は同梱の `.htaccess` でPHP等の実行を禁止しています（画像のみ配信）。
- 定期バックアップは「CSV出力」または ロリポップのDBバックアップ機能をご利用ください。

## SQLite で試す（任意）

MySQLを使わず手軽に試すには、`config.php` で `DB_DRIVER='sqlite'` にすると
`data/manual.sqlite` に保存されます（少人数・簡易用途向け）。本番は MySQL を推奨します。

## 将来のスケール

`db.php` の DSN を差し替えるだけで PostgreSQL 等にも対応可能（PDO）。
画面側（`manual.js`）は変更不要です。
