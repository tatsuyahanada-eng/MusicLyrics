# sideload.jks

自己署名の Android アプリ署名鍵です。CI ビルド同士でアプリの署名を揃え、
「新しいビルドを上書きインストールできる（アンインストール不要）」ようにする
ためだけに存在します。

- Google Play には出しません（このアプリ自体を審査に出せないため）。
- 秘密鍵として扱う必要はありません。Play Store 用の鍵と違い、漏れても
  「誰かが自分になりすましてアプリを更新できる」以上のことは起きません
  （このアプリを配布していないので、悪用できる相手が実質いません）。
- パスワードは意図的に `build.gradle.kts` に直書きしています。

**鍵をローテーションすると、次のビルドは今インストール済みのアプリの
「更新」ではなく「別アプリ」として扱われます。** その場合は一度アンインス
トールしてから入れ直してください。ローテーションする理由は基本的にありま
せん。
