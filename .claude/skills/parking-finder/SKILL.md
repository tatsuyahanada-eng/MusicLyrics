# parking-finder

Google カレンダーの予定を起点に、目的地近くの駐車場を探して予定に追記するスキル。

## このスキルが行うこと（全体像）

```
① 指定された日付の予定をカレンダーから取得
     ↓
② 予定の「場所（location）」欄から住所を取り出す ← これが検索の基準住所
     ↓
③ 基準住所の近くの駐車場を検索（名前・住所）※複数可
     ↓
④ 各駐車場について、基準住所からの距離・所要時間を計算
     ↓
⑤ （可能なら）駐車場の料金の目安を補足
     ↓
⑥ 結果を、その予定の説明欄（description）に追記する
```

## 前提（動かす前に必要なもの）

このスキルは 2 つの外部サービスに依存する。未設定だと動かないので、最初に確認すること。

1. **Google カレンダー コネクタ**（予定の読み取り＋**書き込み**の両方）
2. **Google Maps API キー**（環境変数 `GOOGLE_MAPS_API_KEY`）

セットアップ手順（APIキーの取得場所を含む）は **`references/setup.md`** に詳しく書いてある。
前提が整っていない兆候（下記）が出たら、途中で止めて `references/setup.md` を案内すること。

- カレンダー系の MCP ツールが見つからない → コネクタ未接続
- スクリプトが `GOOGLE_MAPS_API_KEY is not set` を返す → APIキー未設定
- スクリプトが `REQUEST_DENIED` / `API key not valid` / 特定 API の `... is not enabled` を返す → キーが無効か、必要な API が未有効化

## 手順

### 0. 前提の確認

- Google Maps のキーは、まず `echo "${GOOGLE_MAPS_API_KEY:+set}"` で設定有無だけ確認する（値は表示しない）。未設定なら `references/setup.md` を案内して止める。
- カレンダーのツールは名前がコネクタによって変わる。`ToolSearch` で `google calendar events list` のように検索し、予定の一覧取得・取得・更新に使えるツールを特定する。見つからなければコネクタ未接続として `references/setup.md` を案内する。

### 1. 対象の予定を取得する

- ユーザーが指定した日付（「明日」「7月25日」など）を具体的な日付に解決する。曖昧なら確認する。
- カレンダーのツールで、その日の予定を取得する。
- 予定が複数ある場合は一覧をユーザーに見せ、どの予定（またはすべて）の駐車場を探すか確認する。

### 2. 基準住所を取り出す

- 予定の「場所（location）」欄の値を基準住所として使う。
- 場所欄が空、または施設名だけで住所になっていない場合は、そのままだと精度が落ちる。ユーザーに正しい住所を確認するか、施設名でジオコーディングを試みる。

### 3〜5. 駐車場を検索し、距離・所要時間を計算する

`scripts/find_parking.py` を使う。このスクリプトが Geocoding → 駐車場検索 → 距離計算をまとめて行い、JSON を返す。

```bash
python3 .claude/skills/parking-finder/scripts/find_parking.py \
  --address "＜予定の場所欄の住所＞" \
  --radius 500 \
  --max 5 \
  --mode walking
```

- `--radius`: 検索半径（メートル）。都心なら 300〜500、郊外で見つからなければ 1000 以上に広げる。
- `--max`: 取得件数。「複数あってよい」ので既定 5。ユーザー指定があれば従う。
- `--mode`: `walking`（既定）＝駐車場から目的地まで歩く前提の距離・時間。車移動基準なら `driving`。
- 出力は距離の近い順にソートされた駐車場配列。`name`・`address`・`distance`・`duration` を含む。
- スクリプトが `error` キーを返したら、その内容に従って対処する（キー未設定→setup.md、駐車場 0 件→`--radius` を広げて再実行）。

### 5-補. 料金の目安（可能であれば）

- Google Maps API は駐車料金を返さない。必要なら、駐車場名＋「料金」で `WebSearch` / `WebFetch` を使って目安を補足する。
- 確実な情報が取れない場合は無理に載せず、「料金は要現地確認」と明記する。料金は「可能であれば」の付加情報であり、取れなくても他の情報は返す。

### 6. 予定に追記する

- カレンダーの更新ツールで、対象予定の説明欄（description）に駐車場情報を追記する。**既存の説明を消さず、末尾に追記**すること。
- 追記フォーマット（この形を守る）:

```
──── 近隣駐車場（parking-finder 追記 / YYYY-MM-DD 時点）────
基準住所: ＜base_address＞

1. ＜駐車場名＞
   住所: ＜住所＞
   距離: ＜distance＞（徒歩 ＜duration＞）
   料金: ＜分かれば。不明なら「要現地確認」＞

2. ＜駐車場名＞
   ...
```

- 追記後、何をどの予定に書き込んだかをユーザーに一言で報告する。
- 書き込み権限がない／更新ツールが見つからない場合は、追記はせず結果を会話で提示し、その旨を伝える。

## 出力スタイル

- ユーザーには、まず見つかった駐車場を上記フォーマットに近い形で分かりやすく提示し、そのうえで予定に追記した旨を伝える。
- 距離・所要時間は API の返した日本語表記（例「450 m」「徒歩 6 分」）をそのまま使う。

## 補足ファイル

- `scripts/find_parking.py` — 駐車場検索＋距離計算の本体（上記コマンドで実行）。
- `references/setup.md` — Google カレンダー接続と **Google Maps API キーの取得場所・手順**、環境変数の設定方法。前提が未整備のときはここを案内する。
