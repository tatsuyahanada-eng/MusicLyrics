# 力士の写真について

このフォルダに力士の写真を置くと、サイトに表示できます。

## 使い方

1. このフォルダ（`images/`）に画像ファイルを置く
   - 例: `images/hoshoryu.jpg`
   - 推奨: 縦長（おおよそ 4:5）、横 400px 程度、JPG または PNG
2. `data.js` の対象力士に `photo` 欄を追加する

```js
{
  id: 'hoshoryu',
  name: '豊昇龍',
  …
  photo: 'images/hoshoryu.jpg',   // ← 追加
},
```

3. サーバへアップロードして表示を確認

`photo` を設定していない力士は、四股名の頭文字を使ったプレースホルダー（仮画像）が自動表示されます。写真が用意できた力士から順に追加していけば大丈夫です。

## ⚠️ 著作権について

力士・報道機関・日本相撲協会などが権利を持つ写真を、許可なく転載・掲載することはできません。
掲載できるのは次のような写真です。

- 自分で撮影した写真
- 利用許諾を得た写真
- 権利者が再配布を許可している（ライセンス表記のある）写真

公開サイトに載せる前に、必ず利用条件を確認してください。
