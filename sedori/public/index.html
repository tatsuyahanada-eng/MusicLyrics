Amazon PA-API 設定方法

  1. Amazonアソシエイト に登録（無料）
  2. アソシエイトIDを取得後、PA-APIアクセス申請（売上3件以上必要）
  3. サーバーの .env ファイルに以下を設定： 
    AMAZON_ACCESS_KEY=xxx
AMAZON_SECRET_KEY=xxx
AMAZON_PARTNER_TAG=your-tag-22
  4. npm start でサーバーを再起動

※ メルカリ・ヤフオクは外部リンクで価格確認できます（APIなし）
