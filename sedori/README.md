# せどりチェッカー

バーコードスキャンで中古品・本・家電などの仕入れ利益を即座に計算するスマホ向けWebアプリです。

## 機能

- 📷 **バーコードスキャン** - カメラでJANコード・ISBNを読み取り
- 💰 **価格表示** - Amazon新品/中古最安値、出品数
- 🔗 **外部リンク** - メルカリ・ヤフオクの検索ページへワンタップ
- 📊 **利益計算** - Amazon/メルカリの手数料を自動計算
- 📋 **検索履歴** - 過去30件をローカルに保存

## セットアップ

```bash
cd sedori
cp .env.example .env
npm install
npm start
```

ブラウザで `http://localhost:3000` を開く（スマホの場合は同一LAN上でIPアドレスでアクセス）

## Amazon PA-API の設定（任意）

未設定の場合はデモモードで動作します。実際のAmazon価格を取得するには：

1. [Amazonアソシエイト](https://affiliate.amazon.co.jp/) に登録
2. アソシエイト登録後3件以上の売上でPA-APIアクセス申請が可能
3. `.env` に以下を設定:

```env
AMAZON_ACCESS_KEY=xxxx
AMAZON_SECRET_KEY=xxxx
AMAZON_PARTNER_TAG=your-tag-22
```

## 手数料計算ロジック

### Amazon FBA
| 項目 | 計算方法 |
|------|---------|
| 紹介料 | 売価 × カテゴリ別料率（8〜15%） |
| FBA配送代行料 | サイズ別固定（小型¥210〜、中型¥310〜） |
| カテゴリ成約料 | 書籍のみ ¥80 |

### メルカリ
| 項目 | 計算方法 |
|------|---------|
| 販売手数料 | 売価 × 10% |
| 決済手数料 | 売価 × 2.5% |
| 配送料 | ネコポス想定 ¥210（変更可） |

## メルカリ・ヤフオクの価格について

メルカリ・ヤフオクには公式APIがないため、アプリ内での直接価格取得はできません。
「メルカリで確認」ボタンから検索結果ページを開いて確認してください。
